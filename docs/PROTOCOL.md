# Bluetooth-протокол управления

Замок предоставляет один служебный GATT-сервис. Все характеристики доступны только по **зашифрованному и аутентифицированному** соединению (после сопряжения с PIN). Команды принимаются только от телефона, который замок признал своим и который не заблокирован.

| Что | UUID |
|---|---|
| Сервис | `6c5f0001-8d4e-4b1a-9a3f-2f7b5c1d0a01` |
| CMD (запись) | `6c5f0002-8d4e-4b1a-9a3f-2f7b5c1d0a01` |
| RSP (чтение) | `6c5f0003-8d4e-4b1a-9a3f-2f7b5c1d0a01` |

## Как читать ответ

Ответ отдаётся кусками по 240 байт.

1. Запишите в CMD запрос: `s` (статус) или `l` (журнал).
2. Прочитайте RSP. Первый байт: `M` — есть ещё кусок, `L` — последний. Остальное — текст (UTF-8, JSON).
3. Если пришло `M`, запишите в CMD `g1` (затем `g2`, …) и снова прочитайте RSP.
4. Склейте байты всех кусков (без первого байта каждого) и разберите как UTF-8 JSON.

Если телефон ещё не проверен замком, ответ: `{"err":"not ready"}`. Повторите через пару секунд.

## Команды (запись в CMD)

Адрес телефона — `aa:bb:cc:dd:ee:ff` (17 символов).

| Команда | Действие |
|---|---|
| `s` / `l` / `g<N>` | Статус / журнал / следующий кусок ответа |
| `open` | Открыть дверь |
| `pair` / `pairstop` | Открыть / закрыть окно добавления телефона |
| `wifi` / `wifioff` | Включить / выключить Wi-Fi (для обновления прошивки) |
| `reboot` | Перезагрузить |
| `time <unix>` | Установить время (нужно для блокировок на время) |
| `cal <addr>` | Записать текущий сигнал телефона как уровень «у двери» (минус 3 дБм); работает только при выключенном Wi-Fi |
| `lvl <addr> <дБм>` | Задать уровень «у двери» вручную (−110…−25) |
| `calreset <addr>` | Сбросить уровень к значению по умолчанию |
| `ren <addr> <имя>` | Переименовать |
| `blk <addr> <часы>` | Заблокировать на N часов (`0` — бессрочно) |
| `unb <addr>` | Разблокировать |
| `del <addr>` | Удалить |
| `set <ключ> <значение>` | Изменить настройку (таблица ниже) |

### Ключи `set`

| Ключ | Допустимые значения | Смысл |
|---|---|---|
| `rssi` | −110…−25 | Уровень по умолчанию, дБм |
| `hyst` | 2…30 | Запас «ушёл», дБм |
| `conf` | 0…10000 | Сколько мс сигнал держится выше уровня |
| `rearm` | 0…3600 | Секунды «ушедшего» до повторного открытия |
| `grace` | 0…600 | Секунды без открытия после включения |
| `pulse` | 200…10000 | Импульс реле, мс |
| `tx` | 0…7 | Мощность Bluetooth: 0 = −12 дБм … 7 = +9 дБм |
| `woff` | 30…3600 | Выключать Wi-Fi через N секунд без подключений |
| `rlow` | 0 / 1 | 1 — реле срабатывает от LOW |
| `pin` | ровно 6 цифр (можно с нуля) | PIN сопряжения (для новых сопряжений) |
| `ble` | 1…20 символов | Имя в Bluetooth (после перезагрузки) |
| `apssid` | 1…32 символа | Имя Wi-Fi точки |
| `appass` | 8…63 символа | Пароль Wi-Fi точки |
| `webpass` | 4…63 символа | Пароль сервисной страницы |

Результат последней команды (сообщение об ошибке) приходит в поле `m` следующего ответа на `s`.

## Поля статуса (`s`)

`ver`, `ble`, `pin`, `pairing`, `pairLeft`, `maxDev`, `rssiThr`, `rearm`, `pulse`, `tx`, `grace`, `hyst`, `conf`, `woff`, `rlow`, `tv` (часы синхронизированы), `ota` (число OTA-разделов), `wifi`, `ap`, `app`, `wu`, `wp`, `m`, `devices[]`.

Каждый элемент `devices`: `addr`, `name`, `blocked`, `until`, `connected`, `rssi`, `level`, `cal`, `armed`, `raw`.

Журнал (`l`) — массив `{ "ago": секунд назад, "t": "текст" }`, новые первыми.
